For nominal failure modes:
- Use mode central tendency which is the most occurring failure mode, in case two failure modes have the same count, choose one randomly or assign the pair to be the mode value.
- Use frequency dispersion which is simply the display of how the failure modes are distributed in numbers and percentages in a table (table 11.2)

For ordinal complexities per failure mode:
- Use mode central tendency which is the most occurring complexity for the specific failure mode, in case two complexities have the same count, place all samples of those most common complexities in a list and choose the median when there is an odd number of samples, otherwise choose one randomly or assign the pair to be the mode value.
- Use median central tendency which is to place all samples of complexities in a list and choose the median when there is an odd number of samples, otherwise choose one randomly or assign the pair to be the median value.
- Use percentile central tendency if anything interesting about how the data is skewed seems interesting
- Use interval of variation dispersion which is a pair ( X-min, X-max ) to get the complexity interval for each failure mode
